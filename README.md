# BERT and RoBERTa for Automatic Ticket Classification

This repository compares two Transformer-based approaches for assigning customer complaint text to product categories. Both implementations use the CFPB complaint data prepared by the companion [ticket classification project](https://github.com/gizemnurbektas/Automatic-ticket-classification-RNN-LSTM).

## Models

| Path | Implementation |
| --- | --- |
| `Bert` | TensorFlow/Keras fine-tuning with `bert-base-uncased`, tokenization, a stratified train/validation/test split, balanced class weights, early stopping, checkpointing, and a classification report. |
| `Roberta` | PyTorch fine-tuning with `roberta-base`, Hugging Face tokenization, weighted loss, a custom training loop, validation-based early stopping, and macro-F1 reporting. |

These are Colab-exported source files (without `.py` extensions) and include Colab-specific data upload and notebook commands. Open the source in Google Colab and execute it as notebook cells; they are not ready-to-run local Python command-line scripts.

## Dataset

The code expects `filtered_complaints.json` with complaint text in `complaint_what_happened` and category labels in `product`. The dataset is not included in this repository. Upload or mount it in the Colab runtime before running the selected implementation.

## Run in Google Colab

1. Open `Bert` or `Roberta` in Colab.
2. Install the packages required by that implementation in the runtime.
3. Provide `filtered_complaints.json` and run the cells from top to bottom.
4. Review the printed test classification report and training plots.

A GPU is recommended for fine-tuning. Runtime, package versions, available memory, and class distribution can affect execution and results.

## Evaluation

The implementations report class-level precision, recall, and F1. The RoBERTa workflow also tracks macro F1 during validation. Compare the outputs generated by the notebooks for the dataset and configuration you run; this repository does not promise a fixed score.
